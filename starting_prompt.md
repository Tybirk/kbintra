I want to create an "internal communication platform" for our community where we live and eat together

Needs to support:

- Online forum with subgroups where you can upload files in folders, create threads, etc. You should be able to receive notifications either on your phone or via email. 
- An "important posts" section for things that should be pinned and everyone should see
- A module to handle our common food, including
   - Show weekly menu 
   - Make it possible to  register / unregister to eat. 
   - Register your default eating preferences. We eat together Monday to Thursday. Wednesday there should be an option to register for meat or vegetarian. A default preference could then be to eat two persons and one child all 4 days and include meat on wednesday
   - Trade "foodtickets" that you wont get to use anyway, as you made other plans since registering
   - We have duty to cook about once a month, should be possible to "trade" these duties, and some "forum" or some solution to register that you want to trade with anyone and then mark your days
- A calendar where you can register events visible to the whole community
- A "messaging" system like messenger where you can create a thread with one or more persons
- A hub where you can see all houses and their inhabitants, and where those inhabitans can write something about themselves and post a picture
- Users have profile pictures, names, birthdate and phone numbers
- Users are registered invite only
